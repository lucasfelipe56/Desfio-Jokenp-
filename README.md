<h1>Jokenpô</h1>
<br>
<h2>O que se trata?</h2>
<p>É um jogo muito antigo, ele se consiste em escolher entre pedra, papel ou tesoura e é jogado entre duas pessoas.</p>
<br>
<p>Sabendo que papel ganha de pedra, pedra ganha de tesoura e tesoura ganha de papel.</p>
<br>
<h2>O que eu aprende?</h2>
<P>Com esse projeto eu conseguir entender muito mais sobe JavaScript e melhorei minha logica de programação, 
  comparando um valor com outro pra determinar certas ações. </P>
